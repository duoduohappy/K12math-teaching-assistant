# 知序 · 单元教学助手

新增四环节关联开发版：启动后访问 http://127.0.0.1:18769/workflow 。支持材料与版次录入、班级名册、审核教案、课堂分段展示、课堂检测与作业链接、学生提交、缺交统计及反馈回流。尚未内置核实后的官方教材；教案草案是人工填写骨架，不是 AI 生成。完整验收标准见 ACCEPTANCE.md。学生入口无身份验证，仅限本机模拟测试。

七年级数学“一元一次方程”本地 MVP。Python 3.11+，无需第三方依赖。

## 启动

在本目录执行 `python server.py`，浏览器访问 http://127.0.0.1:18769 。也可双击 start.cmd。

## 演示步骤

1. 备课设计：选择移项、去括号或去分母，填写课时和班级情况，生成、修改并审核教案。
2. 随堂练习：生成 1—20 道基础题，查看答案、解析与代入校验，导出材料。
3. 学情反馈：填入模拟数据或上传 CSV，查看知识点正确率与后续教学建议。
4. 历史记录：查看本地 SQLite 中保存的最近 20 次操作结果。

CSV 表头为 student,question_id,answer。答案接受整数、小数和分数；同一学生同一题的重复行会被拒绝。请使用匿名编号。统计只包含提交记录。

## 当前边界

这是独立编写的功能原型，没有复制此前推荐仓库的代码。尚未接入大模型、RAG、真实教材、手写识别或学校账号系统；参考资料仅留存并展示，不参与自动语义理解。教案采用规则模板，练习采用参数化生成与精确分数验算。并不保证题目不重复。模拟数据不代表真实学生结果。教师审核仍然必要。

仅在本机监听；不应直接用于公网或真实学校生产环境。历史数据库位于 classroom.sqlite3，备份整个目录可保留数据。

确认教材版本与可使用资料后，增加按章节、页码和已学知识点过滤的 RAG；再以教师评审样本验证内容正确性、超纲率和引用支持度。模型接入应保留当前确定性数学校验与人工审核流程。
